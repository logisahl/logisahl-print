# LogiSahl Print

Warehouse barcode and label printing for Windows: read the data from Excel or Google Sheets, design the label, print on any Windows printer (thermal label printers or office printers). Free, works offline, bilingual (Arabic / English), with a built-in assistant.

- Website: https://logisahl.com
- Download the latest installer from the [Releases](https://github.com/logisahl/logisahl-print/releases/latest) page (Windows 10 / 11, 64-bit).

On first launch Windows may show a SmartScreen warning because the installer is not yet digitally signed: click **More info**, then **Run anyway**.

This repository holds the website and the published installers. Made by Islam Alhaj.
